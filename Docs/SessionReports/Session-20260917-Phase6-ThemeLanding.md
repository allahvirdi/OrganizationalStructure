# گزارش جلسه — Phase 6 / ThemeLanding

## درخواست
همسویی با SampleAdminPanel، لندینگ ورود، هدایت نشست معتبر به داشبورد و اتصال صفحات به منو.

## نتیجهٔ ادامهٔ جلسه (جایگزین وضعیت اولیهٔ پایین)
- رفع سرریز داشبورد با ستون‌های minmax(0, …) و تک‌ستونی شدن دسترسی سریع زیر ۶۴۰px.
- tsc، lint و build موفق؛ CDP روی ۴۰ ترکیب مسیر/عرض اجرا شد، بدون سرریز سند یا نمایش denied. این آزمون شامل همهٔ مسیرهای جزئیات و عملیات نوشتن نیست.
- در ۳۲۰px: clientWidth = scrollWidth = 314؛ ستون اصلی 282px، ستون‌های داخلی 240px. منوی موبایل در سمت راست با عرض 272px.
- APIهای posts/employees/responsibilities/authorities با نشست موجود 200؛ نبود permission claim در اجرای زنده مستقلاً بررسی نشده است.
- تصاویر هم‌اندازه: اختلاف پیکسل با آستانهٔ 16/255 در 320px برابر 39.9٪ و در 1440px برابر 29.8٪؛ معیار ترکیبی محتوا و ظاهر است، نه درصد خطای چیدمان. خود نمونه در 320px عرض سند 345 داشت.
- تفاوت چیدمان: hero، کارت‌های شاخص، نمودار و ابزارهای هدر مرجع هنوز پیاده نشده‌اند. تفاوت محتوا: اطلاعات واقعی نشست به‌جای فروش و نام کاربر نمایشی نمونه؛ داده ساختگی کپی نشده است.
- تم تیره (پس‌زمینهٔ گزارش‌شده هنوز روشن)، clipping جدول پرسنل و span برچسب مسئولیت نیاز به بررسی دارند.
- برخلاف وضعیت اولیهٔ پایین، تغییرات مجوز و بک‌اند اکنون در working tree موجودند؛ کامیت محدود داشبورد/مستندات آن‌ها را شامل نمی‌شود. تطابق کامل قالب تأیید نیست.

## تغییرات اولیه (تاریخچه)
- هشت فایل Frontend تغییر کرد: تم، CSS، لندینگ، ریدایرکت login، AppShell، RequireAuth، منو و داشبورد.
- پالت ink/brand/secondary و سایه‌های card/float از قالب استفاده شد؛ استایل دکمه با MUI 9 سازگار است.
- `/` فرم ورود، `/login` ریدایرکت به `/` و نشست دارای userId به `/dashboard` هدایت می‌شود.
- پیوندهای چارت، پست‌ها، پرسنل، مسئولیت‌ها و اختیارها در منو و داشبورد موجود است.
- نبود Permission فقط نمایش منو را تغییر می‌دهد؛ RequirePermission و کنترل‌های بک‌اند تغییر نکردند. نمایش منو مجوز دسترسی نیست.

## اعتبارسنجی
- `tsc --noEmit`: موفق.
- `npm run lint`: موفق، بدون هشدار در اجرای نهایی.
- `npm run build`: موفق، ۱۷ مسیر.
- `git diff --check`: بدون خطای whitespace؛ اخطار تبدیل LF به CRLF مشاهده شد.
- مقایسه تصویری و تست تعاملی مرورگر انجام نشد: Playwright/Puppeteer و node_modules قالب مرجع موجود نیست.
- API با پروفایل http راه‌اندازی شد: `/health` روی 5297 برابر 200؛ `/` روی 6300 برابر 200 و `/login` برابر 307 با مقصد `/` است. این آزمون HTTP جایگزین آزمون تعاملی نشست و مقایسه تصاویر نیست.
- قالب مرجع بررسی‌شده فرم ورود ندارد؛ فرم جدید از توکن‌های آن استفاده می‌کند. تطابق پیکسل‌به‌پیکسل پوسته و داشبورد تأیید نشده است.

## محدودیت‌ها و ادامه
- قبل از اعلام تطابق دقیق، تصاویر مرجع و محصول در viewport یکسان و دو تم مقایسه شوند.
- رفتار واقعی نشست معتبر/منقضی و ورود تا داشبورد پس از راه‌اندازی API در مرورگر آزموده شود.
- هیچ تغییر IAM یا بک‌اند و هیچ کامیتی در این مرحله انجام نشد.
- گزارش پیشرفت و ChangeLog به‌روزرسانی شد. تأیید بصری و بازبینی انسانی باقی است.
