# API Contract — Import (ورود ساختار سازمانی از فایل)

**نسخه:** `v1`
**پیشوند:** `/api/v1/import`
**وضعیت:** پیاده‌شده (بخش اول — ساختار پست‌ها)
**تصریح‌دهی:** احراز هویت + `OrganizationStructure.Post.Create` (چون ماهیت عملیات ایجاد پست است؛ مجوز جدید نیازمند ثبت در IAM است و فعلاً از مجوز موجود استفاده می‌شود — کاتالوگ ۲۷تایی حفظ شد)

---

## دامنه

- بارگذاری ساختار سازمانی (پست‌ها) از فایل اکسل (`.xlsx`) برای یک سازمان مشخص.
- هر ردیف یک پست است؛ سلسله‌مراتب با «کد پست والد» در همان فایل ساخته می‌شود.
- فایل نامعتبر یا حاوی خطا → کل عملیات رد می‌شود (Atomic).

---

## قالب فایل اکسل

| ستون | هدر فارسی | اجباری | توضیح |
|------|-----------|--------|-------|
| A | کد پست | بله | کد یکتا درون سازمان (حداکثر ۵۰ کاراکتر) |
| B | عنوان پست | بله | عنوان پست (حداکثر ۲۰۰ کاراکتر) |
| C | شرح | خیر | شرح اختیاری (حداکثر ۱۰۰۰ کاراکتر) |
| D | کد پست والد | خیر | کد پست والد در **همین فایل** یا پست‌های موجود؛ خالی یعنی ریشه |

### قوانین اعتبارسنجی
- ردیف اول باید هدر باشد (ترتیب ستون‌ها مهم است).
- کد پست نباید تکراری باشد (نه در فایل، نه در دیتابیس سازمان).
- کد پست والد باید یا در فایل وجود داشته باشد یا از قبل در دیتابیس ثبت شده باشد.
- حداکثر ۵۰۰ ردیف در هر بارگذاری.
- فرمت فایل فقط `.xlsx` مجاز است.
- حداکثر حجم فایل: ۵ مگابایت.

## Endpointها

### بارگذاری ساختار سازمانی — `POST /api/v1/import/posts`

**Content-Type:** `multipart/form-data`

| پارامتر | نوع | توضیح |
|---------|-----|-------|
| `organizationId` | GUID (form-data) | سازمان مقصد (باید در محدوده کاربر باشد) |
| `file` | File (form-data) | فایل اکسل `.xlsx` |

**پاسخ موفق:** `201 Created`
```json
{
  "importedCount": 15,
  "organizationId": "3fa85f64-..."
}
```

**پاسخ خطا:**

| کد خطا | وضعیت | توضیح |
|--------|-------|-------|
| `Import.InvalidFile` | 400 | فایل خالی، فرمت نادرست، یا بدون ردیف داده |
| `Import.DuplicateCodeInFile` | 400 | کد تکراری در فایل |
| `Import.ParentNotFound` | 400 | کد والد در فایل و دیتابیس یافت نشد |
| `Import.RowLimitExceeded` | 400 | بیش از ۵۰۰ ردیف |
| `Post.DuplicateCode` | 409 | کد در دیتابیس سازمان وجود دارد |
| `Access.Forbidden` | 403 | سازمان خارج از محدوده کاربر |
| `Validation.Failed` | 400 | خطای اعتبارسنجی فیلدها |

---

### دانلود قالب نمونه — `GET /api/v1/import/posts/template`

**پاسخ:** فایل اکسل `.xlsx` با هدر فارسی و یک ردیف نمونه.

| هدر | مقدار نمونه |
|-----|-------------|
| کد پست | MGR-001 |
| عنوان پست | مدیرعامل |
| شرح | بالاترین سطح مدیریتی |
| کد پست والد | |
