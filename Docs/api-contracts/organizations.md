# API Contract — Organizations (واحدهای سازمانی — مرجع IAM)

**نسخه:** `v1`
**پیشوند:** `/api/v1/organizations`
**وضعیت:** پیاده‌شده Phase 6 (نیاز فرم ایجاد پست)
**تصریح‌دهی:** احراز هویت لازم است (`[Authorize]`)؛ Permission دامنه‌ای جدا ندارد (محدوده، نه نقش)

---

## دامنه و منبع داده

- **Master سازمان در IAM است (ADR-002)**؛ این سرویس پایگاه‌داده سازمان ندارد و پاسخ را از
  «محدوده سازمانی نشست» می‌سازد.
- محدوده در زمان ورود/اعتبارسنجی از درخت IAM (`GET /api/organizations/tree`) محاسبه و در نشست
  نگهداری می‌شود: **خود سازمان کاربر + تمام زیرمجموعه‌ها** (`OrganizationScope.ComputeVisibleOrganizations`).
- خروجی هرگز از محدوده کاربر فراتر نمی‌رود؛ اگر سازمان کاربر در درخت IAM پیدا نشود، فهرست
  **خالی** برگردانده می‌شود (fail-closed).
- کاربرد اصلی: فرم‌ها باید سازمان را با **نام** (نه شناسه خام) نمایش دهند و تنها سازمان‌های
  مجاز را قابل انتخاب کنند.

## مدل‌ها

### OrganizationOptionDto (Response)
```json
{
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "name": "شرکت هرسات (محیط توسعه)",
  "code": "herasat-dev",
  "parentId": null,
  "depth": 0,
  "isCurrent": true
}
```

| فیلد | نوع | توضیح |
|---|---|---|
| `id` | GUID | شناسه سازمان (برای ارسال در بدنه درخواست‌ها) |
| `name` | string | نام نمایشی سازمان |
| `code` | string | کد سازمان |
| `parentId` | GUID \| null | شناسه والد **در محدوده**؛ `null` یعنی سازمان خود کاربر (ریشه محدوده) |
| `depth` | int | عمق نسبت به سازمان کاربر (سازمان خود کاربر = ۰) |
| `isCurrent` | bool | آیا سازمان خود کاربر است؟ (انتخاب پیش‌فرض فرم‌ها) |

- ترتیب پاسخ: `depth` صعودی، سپس `name` (بر اساس فرهنگ جاری) صعودی.
- `parentId` والد واقعی در درخت IAM است، اما برای گره ریشه محدوده همیشه `null` گزارش می‌شود تا
  رابط کاربری بتواند درخت را از سازمان کاربر رسم کند.

### Error Contract (یکپارچه — ProblemDetails)
```json
{
  "title": "Validation.Failed",
  "detail": "عبارت جستجوی سازمان حداکثر ۱۰۰ نویسه است.",
  "status": 400
}
```

| کد خطا | وضعیت HTTP |
|---|---|
| `Validation.Failed` | 400 |
| (بدون احراز هویت معتبر) | 401 |

## Endpointها

### فهرست سازمان‌های قابل انتخاب — `GET /api/v1/organizations`

Query:
| پارامتر | نوع | توضیح |
|---|---|---|
| `searchTerm` | string (اختیاری) | جستجوی زیررشته‌ای روی `name` **یا** `code` (بدون حساسیت به بزرگی/کوچکی حروف)؛ حداکثر ۱۰۰ نویسه |

- موفق: `200 OK` + آرایه `OrganizationOptionDto` (بدون صفحه‌بندی؛ اندازه محدوده کاربر کوچک است).
- ناموفق: `400` (searchTerm بلندتر از ۱۰۰ نویسه) / `401` (نشست نامعتبر).
- مجوز: فقط احراز هویت؛ **همه نقش‌های احرازشده** پاسخ یکسان می‌گیرند، چون پاسخ با محدوده سازمانی
  کاربر محدود شده و اطلاعاتی فراتر از آن افشا نمی‌شود (Deny by Default با Fallback Policy حفظ می‌شود).

نمونه — درخواست:
```http
GET /api/v1/organizations?searchTerm=فناوری
```
نمونه — پاسخ `200`:
```json
[
  {
    "id": "8a1d...",
    "name": "معاونت فناوری اطلاعات",
    "code": "IT-DEP",
    "parentId": "fd0e79eb-27b9-4e19-b348-070fa091d5dc",
    "depth": 1,
    "isCurrent": false
  }
]
```
نمونه — پاسخ `400`:
```json
{
  "title": "Validation.Failed",
  "detail": "عبارت جستجوی سازمان حداکثر ۱۰۰ نویسه است.",
  "status": 400
}
```
